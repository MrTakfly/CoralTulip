## CoralTulip 0.6.2: Octave Modifier Chord Keys (`O1`, `o1`, `o2`, `O2`) & Standalone Backup Studio

This release introduces assignable octave modifier chord keys (`O1`, `o1`, `o2`, `O2`), rebrands the firmware to **CoralTulip**, and bundles the standalone desktop **USB-MIDI Backup & Restore Studio** (`flower_backup_app.py`) with a preset backup for **MGMT - Kids**.

### What's new

- **Assignable Octave Modifier Chord Keys (`O1`, `o1`, `o2`, `O2`).** In the `SEL` chord button editor, `TYPE` (Knob 1) now includes `O1` (+1 octave), `o1` (-1 octave), `o2` (-2 octaves), and `O2` (+2 octaves) after `Power`:
  - Holding an octave modifier together with any chord button (or over a latched chord in `Top Lock` / `Side Lock` mode without clearing the latch) transposes the chord and bass root reference by +1, -1, -2, or +2 octaves relative to the global octave setting.
  - Holding an octave modifier alone with no chord button active transposes single notes by +1, -1, -2, or +2 octaves.
  - Multiple octave modifier keys held simultaneously sum their shifts cleanly (clamped to ±4 octaves).
- **Standalone USB-MIDI Backup & Restore Studio (`flower_backup_app.py`).** A zero-dependency desktop GUI & CLI librarian for Windows, WSL, macOS, and Linux:
  - Full 26-object USB-MIDI SysEx backup and restore (`CFS1`, `CFQ6`, `UPB1`, `CFR1`, `CFK1`, `CFD2`, plus VA/FM6 patches).
  - Offline snapshot inspector for global settings, chord buttons, sequencer song/patterns A–H, drum lanes, and user sounds.
  - Native Windows `winmm.dll` USB-MIDI backend and automatic WSL-to-WinMM bridge (no `python-rtmidi` required on Windows or WSL).
- **Bundled Backup (`MGMT - Kids`).** Includes `backups/20261030-194458_MGMT---Kids.json` pre-loaded in the Backup Studio library.
- **CoralTulip Identity & Installer Support.** Updated splash screen, USB device strings (`CoralTulip FM-1`), firmware version string (`CoralTulip 0.6.2`), and native Windows/WSL support in `tools/fm1_install.py`.
